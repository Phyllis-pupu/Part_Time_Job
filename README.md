# 兼职模拟器 · 像素版

> 七天，一千块，别把自己搭进去。

一个反诈题材的文字冒险。你是一个大二学生，摔坏了辅导员的一台相机，要在七天内赔一千块。
手机里全是「日结三百、手机操作、不用经验」的活——看着都像兼职。

**在线玩：** https://phyllis-pupu.github.io/Part_Time_Job/

---

## 简介

大二，七天，一千块。

整台相机翻下窗台，镜头先着地，玻璃裂成一张蛛网。一千块，修相机的说周日到货，卡里剩 63.20。
这一周你能卖的只有时间和体力：驿站搬箱、商场发单、校园执行，按小时结，干到脱力也就百来块。
体力一天回一次，用完了只能等天亮。

于是那些「日结三百、手机操作、不用经验」的消息开始显得合理。借卡走流水、替人取现、
群里当托、发一张二维码——每一条背后都有人替你把话说到最软。手机每天亮几回：辅导员的
通告、本地新闻、王浩的新鞋。可以点开看完，也可以按侧键锁屏。看过的，第七天会变成一句
递到眼前的话；没看的，就真的没了。

像素画面，音乐全部现场合成。四个结局：案底、干净的钱、算得清钱看不透人、没凑够——
只有一个能同时把钱和清醒都留下。

## 怎么玩

| 操作 | 键盘 | 手机 |
|---|---|---|
| 继续 / 跳过打字 | `空格` `回车` | 点画面 |
| 选选项 | `1` `2` `3` `4` | 点按钮 |
| 状态面板 | `E` | 点顶部状态栏 |
| 自动播放 | `A` | — |
| 音乐开 / 关 | `M` | 左上「音乐」 |
| 音效开 / 关 | `F` | 左上「音效」 |

第一次进大厅会弹一次新手指引：**下方看剧情，右侧做兼职**，点一下收起，之后不再打扰。

三条资源线：

- **体力** —— 每天回 60 点，接两趟活就见底。右侧每个兼职图标的左上角写着这一趟要花的
  体力（⚡34 这种），体力不够那格就整块变灰，点进去「去干」是灰的。
- **钱** —— 目标 1000。看不上的活，点进去再退出来，不扣体力。
- **该看清的事** —— 通告、新闻、群里那句提醒，一共八件。手机亮起来的时候，
  你可以点「查看」看完，也可以按侧键「锁屏」。看完才算数。

## 四个结局

| 结局 | 条件 |
|---|---|
| 干净的钱 | 一千凑够了，八件事也都看清了 |
| 算得清钱，看不透人 | 一千凑够了，但该提醒你的话一句没进耳朵 |
| 没凑够 | 周日到了，钱没到 |
| 案底 | 一步涉罪，这七天到此为止。结局页第一块会告诉你：这趟活是电诈链条的第几环、犯的是哪个罪 |

## 关于这份东西

- **单文件**：`index.html` 一个文件 3.7 MB，CSS、JS、71 张图全部内联。
  下载下来双击就能玩，不联网、不装依赖。
- **没有音频素材**：所有音效和七首背景音乐都是 Web Audio 现场合成的
  （方波 / 三角波 / 正弦 / 噪声 + 包络），所以体积几乎不涨。
- **像素画面**：场景、人物、手机界面、那辆车，都在代码里画/生成，不是贴图库。
- **手机是真的**：锁屏、聊天、好友申请三套界面，截图那张通告能真的滑着读完。
- 人物与情节虚构；涉及的罪名与法条（帮信、掩隐、诈骗共犯）按现行法律引述，
  不构成法律意见。

## 本地运行

```bash
# 直接打开
open index.html

# 或者起个本地服务器（音效在 file:// 下也正常，但这样更接近线上）
python3 -m http.server 8000
# → http://localhost:8000
```
